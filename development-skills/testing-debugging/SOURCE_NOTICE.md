# 调试 Skill 来源与许可说明

本目录中的系统化调试规则参考并重新整理自：

- 项目：Superpowers
- 仓库：https://github.com/obra/superpowers
- 参考模块：`skills/systematic-debugging/`、`skills/verification-before-completion/`
- 原作者：Jesse Vincent / obra
- 原项目许可：MIT License

本项目没有直接照搬完整原文，而是结合以下环境重新编写：

- Android APK 构建、签名、安装、覆盖升级和加固兼容；
- PHP 7.4 / 8.2、MySQL 5.6/5.7 / 8.0；
- 安卓手机 KSWEB 与共享存储；
- App、Web、PC 双端/三端接口和数据流；
- 用户常见的“AI连续修补但仍然报错”场景。
