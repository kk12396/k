# 来源与参考说明

本目录为针对玄忆工作室开发环境和交付习惯重新编写的规则集合，不是任何上游项目的完整复制。

设计思路参考了以下公开项目的工作流与组织方式：

- UI/UX Pro Max Skill：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- Superpowers：https://github.com/obra/superpowers
- Anthropic Skills：https://github.com/anthropics/skills
- OpenAI Skills：https://github.com/openai/skills
- Vercel Agent Skills：https://github.com/vercel-labs/agent-skills
- Trail of Bits Skills：https://github.com/trailofbits/skills
- GitHub Awesome Copilot：https://github.com/github/awesome-copilot

本目录内容重点结合并补充了：

- 旧版 PHP7.4 + MySQL5.6/5.7 与新版 PHP8.2 + MySQL8.0 的明确选择。
- `/adminsc`、安装器、共享迁移链和移动端 KSWEB 兼容要求。
- 普通 Android 与明确要求 AIDE/AIDE-Plus 的不同交付边界。
- 双端/三端共享契约、APK/EXE/网页版源码交付规则和本地优先策略。
- 移动端状态栏/手势安全区、Android 自适应图标和正式产品验收。

引用、复制或再分发上游项目的原始内容时，应继续遵守各上游仓库自身的许可证。本文档不改变任何上游项目的版权或许可条件。
