# 精选多风格 UI Skill

这是从 `ui-ux-pro-max-skill` 中选取并重新整理的中文 UI/UX 开发规则，覆盖以下方向：

- Minimalism & Swiss Style
- Neumorphism
- Glassmorphism
- Claymorphism
- Aurora UI
- Flat Design
- Skeuomorphism
- Liquid Glass
- Micro-interactions
- Soft UI Evolution
- Bento Box Grid
- Y2K Aesthetic
- AI-Native UI
- Bento Grids
- Spatial UI / VisionOS
- Tactile Digital / Deformable UI

## 给 AI 读取的主文件

- GitHub 页面：https://github.com/kk12396/k/blob/main/ui-style-library/SKILL.md
- Raw 直链：https://raw.githubusercontent.com/kk12396/k/main/ui-style-library/SKILL.md

开发网站、App、PC客户端、插件或后台前，先读取 `SKILL.md`，根据产品定位选择主风格并建立设计系统，不要默认套用暖黄、米白、大圆角卡片或紫色渐变。
